# Bookverse Reading Nook

Act as a senior full-stack software engineer, UI/UX designer, database architect, and product developer.

I want you to design and develop a professional, scalable, production-oriented digital reading platform called BOOKVERSE.

This is a real business project, not a college demo or static frontend. The application must be designed for real customers, authors, and administrators.

1. BUSINESS OVERVIEW
Website Name: BOOKVERSE
Tagline: One Platform. Endless Stories.
Business Model:
BOOKVERSE is an online digital reading platform where users can discover, purchase, and read digital books.
The platform should support:
* eBooks, Novels, Short stories, Comics, Manga, Tamil books, English books, Independent author publications, Audiobooks (future expansion)
Target Audience:
* Students, Book lovers, Tamil readers, English readers, Novel readers, Comic and manga readers, Independent authors

2. TECHNOLOGY STACK
Frontend: React.js, TypeScript, Tailwind CSS, Modern responsive UI components, Lucide icons
Backend: Supabase (Auth, PostgreSQL, Storage, Edge Functions)
Payment Gateway: Razorpay for Indian payments
Architecture requirements: Clean and reusable components, modular folder structure, secure API communication, database-driven content, scalable architecture. Do not expose secret keys or sensitive credentials in frontend code.

3. PROFESSIONAL UI/UX DESIGN
Create a premium, modern, visually attractive design inspired by professional digital reading platforms like Kindle and modern streaming services.
Brand colors:
* Primary: Deep navy / dark purple.
* Secondary: Violet.
* Accent: Gold.
* Background: White and soft grey.
* Dark mode: Deep charcoal.
Create a consistent BOOKVERSE brand identity with light and dark reading modes, clean typography, attractive book cards.

4. HOMEPAGE
Build a professional homepage with:
* BOOKVERSE logo & navigation (Home, Explore, Categories, Free Books, Premium, Authors, Login / Register, User profile)
* Hero section with headline: “Discover Your Next Favourite Story.”
* Search bar for books, authors, genres, and categories
* Sections: Trending Books, Popular Novels, Tamil Books, English Books, Comics and Manga, Recently Added Books, Free Reading Collection, Premium Collection, Featured Independent Authors, Membership promotion, Testimonials, Footer.
Use realistic sample book data for preview.

5. USER AUTHENTICATION & ROLES
Customer, Author, Admin roles with registration, login, profile, and account settings.

6. BOOK DISCOVERY SYSTEM
Browse, search by title/author/category, filters (language, price, rating, popularity), categories (Novels, Short Stories, Romance, Thriller, Fantasy, Sci-Fi, Comics, Manga, Tamil Literature, English Literature).

7. ONLINE READING SYSTEM
Reader interface with page navigation, reading progress, bookmarks, font size adjustment, light/dark reading themes, continue reading.

8. FREE READING & 9. REWARDED AD SYSTEM PLACEHOLDER
Clear architecture for ad-free time rewards and non-intrusive placements.

10. PREMIUM MEMBERSHIP
Plans (Monthly ₹79, Quarterly ₹199, Half-Yearly ₹399, Yearly ₹699) with clear benefits.

11. INDIVIDUAL BOOK PURCHASE
Storefront support for purchasing standalone titles (Short Stories ₹9-₹19, eBooks ₹19-₹49, Novels ₹49-₹99, Comics ₹19-₹49, Manga ₹29-₹59).

12. PAYMENT INTEGRATION (Razorpay architecture)
13. AUTHOR DASHBOARD (Submissions, manuscript uploads, sales, earnings, 70/30 revenue share)
14. ADMIN DASHBOARD (Users, authors, books, approval queue, transactions, settings)
15. USER DASHBOARD (My Library, Purchased Books, Reading History, Bookmarks, Wishlist, Settings)

DEVELOPMENT APPROACH:
Start with PHASE 1:
- Complete professional UI
- Homepage
- Navigation
- Login and registration screens / modals
- Explore page
- Categories
- Book details page
- Free books page
- Premium page
- Online reader modal/page preview
- Customer dashboard layout
- Author dashboard layout
- Admin dashboard layout
- Responsive mobile design
- Reusable components
- Rich realistic sample data (Tamil books, English novels, comics, manga)
